# NicolasJAVA

Repositório com meus estudos e exercícios em **Java**, feito durante meu aprendizado como iniciante em programação.

## 📚 O que tem aqui

Exercícios organizados na pasta [`Curso/src`](./Curso/src), cobrindo desde a base da linguagem até conceitos de orientação a objetos:

- Fundamentos: variáveis, `if/else`, `switch`, laços `for`/`while`/`do-while`, operadores lógicos
- Estruturas de dados: arrays, busca em vetores
- Métodos: criação, sobrecarga (overload) e reaproveitamento de código
- Orientação a objetos: classes, construtores e sobrecarga de construtores (`Car`, `Students`, `User`, `Width`)
- Mini projetos aplicados: calculadora com `switch`, jogo de adivinhação de número, lançador de dados, simulador bancário, quiz e cálculo de juros
